# Mihon Sources

My Mihon extension sources.

## Add to Mihon

Use this repository URL:

- https://raw.githubusercontent.com/imonteiroyh/mihon-sources/main/repo.json

Direct index URL:

- https://raw.githubusercontent.com/imonteiroyh/mihon-sources/main/index.pb

## Update

Edit `index.min.json` and run `update.ps1`. GitHub Actions also regenerates
`index.pb` automatically after changes are pushed to `main`.
